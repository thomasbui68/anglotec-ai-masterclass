The Anatomy of a Great Prompt

Every great prompt has these elements:

  • Role: "Act as a [expert role]"
  • Context: Background information
  • Task: What you want done
  • Format: How you want the output
  • Constraints: Length, tone, style limits

Writing Prompts (20 Templates)

  • "Write a [tone] blog post about [topic] for [audience]. Include [specific elements]."
  • "Create an outline for a [word count] article about [topic]."
  • "Rewrite this in [style]: [paste text]"
  • "Generate 10 headlines for [topic] that drive clicks."

Coding Prompts (20 Templates)

  • "Write a [language] function that [description]. Include error handling."
  • "Review this code for bugs and best practices: [paste code]"
  • "Convert this [language A] code to [language B]."
  • "Create a [type] test suite for this code: [paste code]"

Business Prompts (20 Templates)

  • "Analyze the [industry] market and identify 3 growth opportunities."
  • "Create a SWOT analysis for [company/product]."
  • "Write a business plan executive summary for [business idea]."
  • "Generate 5 customer personas for [product/service]."
